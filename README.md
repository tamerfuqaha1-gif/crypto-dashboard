# CryptoDash

Dashboard interactif de visualisation de données crypto.

##  Stack technique
- Python
- Streamlit
- Plotly
- Pandas

##  Fonctionnalités
- KPI cards avec variation 24h en temps réel
- Graphique des prix par crypto
- Graphique de variation 24h (vert/rouge)
- Camembert de répartition des prix
- Tableau des données brutes

##  Lancer le projet
```bash
pip install -r requirements.txt
streamlit run dashboard.py
```
